# Changelog

All notable changes to this project will be documented here.

## 1.0.0 - 2026-08-01

### Added

- Manifest V3 toolbar workflow with domain-aware automatic application.
- AES-256-GCM encrypted local vault and PBKDF2 master-password derivation.
- Browser-session unlock key storage.
- Automatic autofill, ten-second toast, optional clipboard copy, and success popup.
- Manual fallback selector for unmatched sites.
- Options interface for entry management, JSON transfer, settings, and password rotation.
- Unit tests, source validation, Webpack production build, and extension icons.
